# AI代行 事業プラン（たたき台）

## ⚠️ 最初に必ず確認（開始前の条件）
F-1ビザの留学生は、学外での就労・自営に制限があります（ブログ記事「留学生はアメリカでアルバイトできる？」の通り）。
**有料で代行を受ける前に、大学のDSO（国際学生オフィス）または移民弁護士に「オンラインで日本向けに有償サービスを提供してよいか」を確認してください。** 答えが出るまでは、出品・集客・受注はせず、準備（下記の文面づくり・実績づくり）だけ進めます。

## 納品フロー
1. ヒアリング（ターゲット、NGワード、参考アカウント）
2. 構成案を提出 → 承認
3. AIで下書き → 事実確認・修正・PR表記チェック
4. 納品（修正1回込み）
5. 希望者には予約投稿の設定まで

## 品質ルール（信用を守る）
- 数字・制度・料金は必ず公式情報で確認し、確認できないものは書かない。
- 体験談は依頼者本人の実体験のみ。創作しない。
- アフィリエイト/PRは冒頭に明記（日本のステマ規制）。
- AIを使うこと自体は隠さない。
